# Google Sheet 後端

讓「列印工作台」把資料同步到自己的 Google 試算表。App 本身還是離線可用，
Google Sheet 是第二份備份，也方便在電腦上用試算表看、排序、畫圖表。

## 一、建立試算表與指令碼

1. 到 [sheets.new](https://sheets.new) 開一份新試算表，命名成你喜歡的名字（例如「列印工作台資料」）。
2. 選單 **擴充功能 → Apps Script**，會開一個新分頁。
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上 [`Code.gs`](./Code.gs) 的全部內容。
4. 改第一個常數：

   ```js
   const TOKEN = 'CHANGE-ME-換成你自己的長字串';
   ```

   換成一段只有你知道的長字串（建議 20 字以上，英數混合）。這是唯一的門鎖，
   因為部署後網址是公開的。**不要**用你 Google 帳號的密碼。

5. 存檔（Ctrl+S）。
6. 在上方函式下拉選單選 **setup**，按 **執行**。第一次會跳授權畫面：
   選自己的帳號 → 「進階」 → 「前往 …（不安全）」 → 允許。
   這個「不安全」是因為指令碼沒有經過 Google 審查，你自己寫的都會這樣。

   執行完 **執行紀錄** 會印出試算表網址，同時建立 `_meta`、`_schema` 兩張隱藏工作表。

## 二、部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**。
3. 設定：
   - 說明：隨便填，例如 `v1`
   - **執行身分：我**
   - **誰可以存取：任何人**  ← 選「任何擁有 Google 帳戶的人」會失敗，App 沒辦法帶登入狀態
4. 按 **部署**，複製 **網頁應用程式網址**，長得像：

   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

   用瀏覽器直接打開這個網址，應該看到 `{"ok":true,"service":"列印工作台 backend",...}`。

## 三、在 App 裡設定

打開「列印工作台」→ **設定 → 雲端同步**：

- **網頁應用程式網址**：貼上剛剛那串 `/exec` 網址
- **密鑰**：填 `Code.gs` 裡的 `TOKEN`
- 按 **測試**，看到「連上「…」」就成功了
- 按 **上傳**，把目前手機上的資料寫進試算表

網址和密鑰存在這台裝置的 localStorage，不會送到 Google 以外的地方。
換裝置要重新填一次，填完按 **下載** 就把資料拉過來。

## 四、日常使用

| 按鈕 | 做什麼 |
| --- | --- |
| 測試 | 確認連得上、看雲端現在有幾個分類 |
| 上傳 | 本機整包蓋過雲端 |
| 下載 | 雲端整包蓋過本機（會先跳確認） |

這是**手動整包覆蓋**，不是即時雙向同步。習慣上：在手機上改完按一次上傳，
換一台裝置先按下載。

如果雲端有你在另一台裝置上傳的較新版本，上傳會被擋下來並提示
「雲端資料比你手上的新」，接著問你要不要強制覆蓋——確定手上這份才是要留的再按。

## 試算表長什麼樣

- 每個分類一張工作表，名稱就是分類名稱（設備、耗材、…）
- 第一列是欄位名稱，**A 欄 `id` 是 App 的內部編號，不要動**
- `_meta`、`_schema` 是給程式看的，預設隱藏。`_schema` 存欄位定義，刪掉會讓下載失敗

### 可以直接在試算表裡改嗎

可以改**儲存格的值**，改完在 App 按「下載」就會吃進去。

不要在試算表裡做這些事，它們不會被正確讀回來：

- 新增／刪除欄（欄位結構請在 App 的「設定」裡改，再按上傳）
- 改第一列的欄位名稱
- 改或清空 A 欄的 `id`（清空的話下載時會被當成新紀錄，配一個新編號）

新增紀錄的話，直接在最後一列填就好，`id` 留空即可，下載時會自動補。

## 安全性

- 網址是公開的，**擋住別人的只有 `TOKEN`**。不要把網址加密鑰一起貼到公開的地方。
- 密鑰外流的話：改 `Code.gs` 的 `TOKEN`，重新部署（**部署 → 管理部署作業 → 編輯 → 版本選「新版本」**），
  再回 App 改成新的密鑰。網址不會變。
- 指令碼只會動到自己那份試算表，不會碰你 Drive 的其他檔案。

## 改了 Code.gs 之後

一定要重新部署才會生效：**部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」 → 部署**。
只按存檔是不夠的。網址不會變，App 那邊不用改。
